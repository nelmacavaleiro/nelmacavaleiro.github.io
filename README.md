# Nelma Cavaleiro | Portfolio

**Live site:** [nelmacavaleiro.github.io](https://nelmacavaleiro.github.io)

Personal portfolio presenting my work across business analysis, solution design, data and AI. It includes case studies on Nupcial, a live two-sided wedding planning platform; an AI Deployment Sprint with Manchester Digital and Manchester Metropolitan University; operational and process improvement work at Brand Addition; and my MSc in Information Systems Management at the University of Sheffield.

## About the site

- Built with HTML, CSS and JavaScript, without frameworks
- Multi-page structure with a consistent design system defined through CSS variables
- Responsive layout with automatic light and dark mode
- Accessibility features, including semantic HTML, keyboard focus styles and reduced-motion support
- Hosted on GitHub Pages and deployed automatically through a GitHub Actions workflow
